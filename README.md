## 💻 Projeto

O projeto Minas das Minas consiste no desenvolvimento de uma página web para divulgar a Carreta Itinerante, reunindo informações sobre a exposição, agenda, cidades visitadas e conteúdos sobre mineração e a história de Minas Gerais.
